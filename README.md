# Debug English 🐧

**Inglês para situações reais de trabalho em tecnologia.**

O Debug English é um projeto em desenvolvimento para ajudar profissionais e estudantes de TI a praticar entrevistas de emprego, *daily meetings*, *code reviews* e reuniões técnicas em inglês.

🌐 **Site:** https://sergiojr06.github.io/debug-english/  
📝 **Lista de espera:** https://tally.so/r/q5RKP7

## Status do projeto

> **Pré-lançamento / validação de interesse.** O site público é uma landing page com uma demonstração interativa. Ainda não oferece entrevistas conduzidas por IA nem avaliação automática de respostas.

### O que funciona hoje

- Apresentação do produto, da proposta e dos cenários de prática.
- Seleção de área de TI e cenário, com prévia instantânea de perguntas.
- Campo para ensaiar respostas por texto, com contagem de palavras e dicas de estrutura.
- Lista de espera integrada ao Tally.
- Layout responsivo e interações do mascote.

**Observação:** as respostas digitadas na demonstração não são enviadas para correção nem avaliadas por IA. As notas exibidas no relatório do site são apenas ilustrativas.

## Roadmap

| Fase | Objetivo | Status |
| --- | --- | --- |
| Landing page | Explicar a proposta e captar interessados | ✅ Publicada |
| MVP 0.1 | Entrevista guiada com cinco perguntas e resumo da sessão | Planejado |
| MVP 0.2 | Histórico e acompanhamento de prática | Planejado |
| MVP 0.3 | Experimentar respostas por voz e acessibilidade | A avaliar |
| MVP futuro | Feedback contextual e entrevistas conversacionais com IA | A avaliar após validação |

O foco inicial é **validar a utilidade do produto com usuários reais antes de assumir custos de infraestrutura ou APIs**.

## Tecnologias utilizadas

- HTML5, CSS3 e JavaScript (sem frameworks)
- SVG e Web Audio API para elementos interativos
- GitHub Pages para hospedagem
- Tally para a lista de espera

## Executar localmente

1. Faça o download deste repositório.
2. Abra o arquivo `index.html` em um navegador moderno.
3. Para testar em um servidor local, use a extensão Live Server do VS Code ou outro servidor HTTP estático.

Não é necessário configurar um backend para visualizar a versão atual.

## Como ajudar

- Acesse o [site público](https://sergiojr06.github.io/debug-english/).
- Experimente selecionar uma profissão e um cenário.
- Envie sugestões e relatos de bugs pela aba **Issues** deste repositório, evitando compartilhar informações pessoais.

## Privacidade e transparência

A lista de espera é operada pelo Tally e solicita dados de contato e preferências informados voluntariamente. A demonstração de perguntas no site não realiza avaliação por IA. Antes da ampliação da plataforma, serão publicadas informações completas sobre tratamento de dados e canais para solicitações de privacidade.
